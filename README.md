# AutomationPractice_EcommerceFlow

E-commerce Automation TestNG This is a complete project where an E-commerce site site is automated by writing test suites using Selenium-Webdriver and TestNG as testing framework 

The following key modules/pages are automated:  
SignUp 
Login 
Search 
Cart 
Checkout 

Key test cases (total 51) are written for each module and test suites created including the positive and negative test cases. 
A state-transition flow of test-cases are designed and run like a user buying a product from an e-commerce site. For failed test cases it will take a screenshot as well at the point of failure.

Tool: Selenium Webdriver, Java Testing Framework : TestNG
